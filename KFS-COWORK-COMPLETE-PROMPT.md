## 3. DESIGN DIRECTION — "PARAMETRIC ROYAL / CYBER CINEMATIC"

The site must feel **alive and generative**, not template-made:

- **Parametric = the page is generated by parameters.** A real-time WebGL canvas behind everything
  (golden galaxy, flowing parametric field, particles) whose behavior is driven by scroll + mouse position.
  Dark obsidian base (`#05070B`) + royal gold (`#C9A84C` / bright `#F5C842`), cyan/green accents.
- **Fluid** — everything scales with `clamp()`: typography, spacing, grid. Nothing fixed-width.
- **Immersive** — full-bleed canvas, grain overlay, custom cursor, preloader, cinematic section reveals.
- **Interactive** — mouse-reactive canvas, magnetic buttons, 3D tilt cards, FAQ accordion, count-up stats,
  portal orb (3D floating client-portal bubble).
- **Parallax** — layered depth: background canvas scrolls at a different rate than content; hero elements
  drift at multiple speeds; camera/field shifts as you scroll.

## 5. TECH STACK (self-contained single file)

- **One file:** `index.html` — inline CSS + inline JS. No build step. `style.css`/`main.js` can remain
  for the legacy page but the live page must not depend on them.
- **CDNs (pinned):**
  - GSAP 3.12.5 + ScrollTrigger (`cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/...`)
  - Three.js r128 (`cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`)
  - Google Fonts (Cinzel, Cormorant Garamond, DM Sans, JetBrains Mono)
- **Deployment:** Docker nginx on :8081 (`docker-compose.yml`, `nginx/nginx.conf`). Dockerfile copies
  `index.html`, `style.css`, `main.js` — rebuild container after changes:
  `docker compose up -d --build` in `~/kfs-website`.

## 8. SKILLS THE DEVELOPER SHOULD HAVE / LEARN

Representing a web developer means the build uses real craft:

- **WebGL / Three.js** — custom shader particles, scene graph, lights, render loop.
- **GSAP + ScrollTrigger** — scroll-scrubbed camera, progress bar, reveals, stagger.
- **Parametric / generative design** — math-driven layout & motion (clamp, sin/cos, golden ratio).
- **CSS architecture** — design tokens, fluid type, grid, glass/glow, responsive, reduced-motion.
- **Vanilla JS** — observers (IntersectionObserver), event delegation, form fetch, canvas resize.
- If a new technique is needed mid-build (e.g. a shader trick, ScrollTrigger pinning), learn it from docs
  before applying — the site must ship without console errors.
